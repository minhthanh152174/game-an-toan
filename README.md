# Game giáo dục phòng chống đuối nước và tai nạn thường gặp (3D)

Game 3D góc nhìn thứ nhất dạy học sinh cách xử lí an toàn trong các tình huống thường gặp:
điện thoại và sạc pin, nước tràn ổ điện, cháy bếp ga, đi đường và đèn giao thông, cứu người
đuối nước ở cầu, cháy ở phòng thực hành Hoá học và thoát hiểm, ba sự cố trong giờ thể dục
(bóng rơi xuống ao, bạn ngã bất tỉnh, giông sét).

Mỗi lựa chọn đúng hay sai đều có giải thích khoa học. Có chấm điểm, bảng xếp hạng,
tài khoản học sinh (thầy giáo phê duyệt), và chế độ "đến trường gặp các bạn" để nhiều
người chơi gặp nhau, chat trong sân trường.

Tác giả ý tưởng và kịch bản: thầy Nguyễn Xuân Khiêm.

## Các file

- `index.html` — game chính (trang web công khai)
- `game-3d.html` — bản giống hệt để tải về chạy ngoại tuyến
- `game-3d-xem.html` — bản chỉ xem: bay tự do xem mọi cảnh, không thử thách

Game là một file HTML duy nhất, dùng three.js r128 và Firebase.
